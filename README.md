# 麻雀団体管理簿

## ▶ [ここを押すとアプリが開きます](https://nb-saki.github.io/mahjong-league/)

四人麻雀・三人麻雀の団体戦を記録するWebアプリです。HTMLファイル1つで動き、サーバーは要りません。

## できること

- メンバー（本名・アカウント名）の登録とチーム分け（ランダム振り分けあり）
- 半荘ごとの結果入力 → チームpt・個人成績を自動計算
- 対局ごとのpt倍率（×1.5、×2 など）
- 対局履歴・個人成績のCSV出力、推移グラフ（PNG保存）
- 雀魂の終局画面スクショ読み取り（任意。「ルール」画面で自分の Claude APIキーを入れた端末だけ）

## 点数ルール

| | 四人麻雀（Mリーグ準拠） | 三人麻雀 |
|---|---|---|
| 持ち点／返し | 25,000／30,000 | 35,000／40,000 |
| ウマ | +30／+10／−10／−30 | +20／0／−20 |
| オカ | +20 | +15 |

pt =（持ち点 − 返し）÷ 1000 + ウマ + オカ（1位のみ）

## 使い方

`index.html` をブラウザで開くか、GitHub Pages などで公開します。記録は開いたブラウザの中に保存されます（人ごとに別データ）。
