# 麻雀団体管理簿

## ▶ [ここを押すとアプリが開きます](https://nb-saki.github.io/mahjong-league/)

大会のルールは [ルールブック](#麻雀団体戦-ルールブック) を見てください。

四人麻雀・三人麻雀の団体戦を記録するWebアプリです。HTMLファイル1つで動き、サーバーは要りません。

## できること

- メンバー（本名・アカウント名）の登録とチーム分け（ランダム振り分けあり）
- 半荘ごとの結果入力 → チームpt・個人成績を自動計算
- 対局ごとのpt倍率（×1.5、×2 など）
- 対局履歴・個人成績のCSV出力、推移グラフ（PNG保存）
- 雀魂の終局画面スクショ読み取り（任意。「ルール」画面で自分の Claude APIキーを入れた端末だけ）

## 点数ルール

| | 四人麻雀（Mリーグ準拠） | 三人麻雀 |
|---|---|---|
| 持ち点／返し | 25,000／30,000 | 35,000／40,000 |
| ウマ | +30／+10／−10／−30 | +20／0／−20 |
| オカ | +20 | +15 |

pt =（持ち点 − 返し）÷ 1000 + ウマ + オカ（1位のみ）

## 使い方

`index.html` をブラウザで開くか、GitHub Pages などで公開します。記録は開いたブラウザの中に保存されます（人ごとに別データ）。

# 麻雀団体戦 ルールブック

2026年11月2日版

## はじめに

この大会はチーム対抗の団体戦です。各チームのメンバーが半荘を打ち、全員のポイントの合計でチームの順位を決めます。

- 三人麻雀（三麻）で行います。
- 順位点はMリーグと同じ考え方（返し・ウマ・オカ）で、数値はネット麻雀・雀荘で一般的な三麻のものを使います。
- 成績はすべて「麻雀団体管理簿」で記録・集計します。チーム順位と個人成績はアプリでいつでも確認できます。
- 大会後半はポイント倍率をかけることがあり、終盤まで逆転が起こりやすい仕組みになっています。

## 開催日時・場所

2026年12月30日（水）の1日で行います。場所など未定の項目は、決まり次第書き込んでください。

| 項目 | 内容 |
|---|---|
| 日時 | 2026年12月30日（水）11:00〜19:00 |
| 場所 | 雀魂 友人戦（ルーム番号は当日連絡）／会場名・住所 |
| 形式 | 三人麻雀、半荘戦 |
| 進行 | 2卓同時進行、各卓8半荘（合計16半荘） |
| 1半荘の目安 | 約1時間（8時間で8半荘） |
| 倍率をかける対局 | 第5半荘から（×1.5） |

## 開催ルール

各半荘の終局時の持ち点と順位からポイント（pt）を計算し、チーム全員の合計で順位を決めます。計算はアプリが自動で行います。

### 順位点

| 項目 | 三人麻雀 |
|---|---|
| 持ち点 | 35,000点 |
| 返し | 40,000点 |
| ウマ | 1位 +20／2位 0／3位 −20 |
| オカ（1位に加算） | +15 |

### ptの計算式

pt =（終局時の持ち点 − 返し）÷ 1000 + ウマ + オカ（1位のみ）

小数点以下第1位までで丸めます。卓の3人のptの合計は必ず0になります。

| 例 | 1位 | 2位 | 3位 |
|---|---|---|---|
| 持ち点 | 51,000 | 36,000 | 18,000 |
| pt | +46.0 | −4.0 | −42.0 |

### 同点のとき

終局時に同点の場合は上家取りとします。起家に近い席の人を上位とし、順位点は分けません（雀魂と同じ扱い）。

例：起家が東家のとき、南家と西家が同点なら南家が上位です。アプリでは「ルール」画面の同点の扱いを「起家優先」にして集計します。

### ポイント倍率

大会後半など、運営が指定した対局ではチームptに倍率をかけます。

- 倍率は対局ごとに×1・×1.5から選びます。例：×1.5の対局で1位+46.0なら、チームには+69.0が入ります。
- 個人成績は、倍率をかけない元のptで集計します（アプリの設定で倍率込みに切り替え可能）。

### 順位の決め方

- **チーム順位**：所属メンバー全員のチームpt（倍率込み）の合計で決めます。
- **個人成績**：合計pt、平均pt、平均順位、トップ率、連対率、ラス回避率、最高素点などをアプリで確認できます。

### 対局ルール（雀魂の友人戦設定）

雀魂の友人戦（三人麻雀）の初期設定で対局します。

## 準備類

運営は大会前日までにアプリへの登録とチーム分けを終えます。参加者は雀魂のアカウント名を運営に伝えるだけです。

### 運営

- [ ] 「ルール」画面で、同点の扱いを「起家優先」にし、個人成績に倍率を含めるかどうかを設定する
- [ ] 「メンバー・チーム」画面でチームを作る
- [ ] 参加者全員の本名と雀魂アカウント名を登録する
- [ ] チームに振り分ける（手動、またはランダム振り分け）
- [ ] 雀魂の友人戦ルームのルール設定を決め、全員に共有する
- [ ] 倍率をかける対局と倍率を決め、事前に告知する

### 参加者

- [ ] 雀魂のアカウントを用意し、アカウント名を運営に伝える
- [ ] 運営と雀魂でフレンドになっておく
- [ ] 対局できる通信環境と端末を用意する（充電も忘れずに）
- [ ] 昼ごはんを持ってくる（持ち込み推奨。半荘の合間に手早く食べられるもの）
- [ ] 会場で打つ場合は、11:00の開始までに会場へ到着する

## 注意事項

結果は対局終了後すぐに、終局画面のスクリーンショットで運営へ報告してください。報告された結果をもとに運営がアプリへ入力します。

### 結果の報告

- 終局画面（全員の名前と持ち点が写った画面）を撮影して送ります。送るのは卓の代表者1人で構いません。
- 持ち点は供託などを含めた終局時の点数です。3人の合計が105,000点になることを確かめます。
- 入力の誤りに気づいたら、運営に連絡してください。対局履歴から修正します。

### 対局中のマナー

- 遅刻や欠席は、分かった時点で連絡お願いします！
- 同じチームのメンバーが同じ卓に入らないように組み合わせを決めます。
- 楽しく打ちましょう！

### トラブルのとき

- 通信が切れた場合、雀魂の自動打牌のまま対局を続け、結果はそのまま有効にします。
- その他なにかあれば運営まで連絡お願いします。

### 記録の保存

- 記録は運営の端末のアプリ内に保存されます。参加者が同じURLを開いても、運営の記録は表示されません。
- 途中経過は、運営がチーム順位の画面やグラフ画像、CSVを定期的に共有します。
